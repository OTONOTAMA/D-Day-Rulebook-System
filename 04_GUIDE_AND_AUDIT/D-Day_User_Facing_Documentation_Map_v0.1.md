# D-Day User-Facing Documentation Map v0.1

**STATUS: USER-FACING NAVIGATION GUIDE**
**DATE: 2026-09-12**

このD-Day Rulebook Systemでは、読む目的によって本を使い分けます。

## 日本語3冊

| 本 | 役割 | こんな時に読む |
|---|---|---|
| **A2 日本語 Player Rulebook** | 正式な処理手順 | 「今この処理をどうやる？」 |
| **A4 日本語 Rules Companion** | ルール理解の教科書 | 「なぜこのルールなの？ 何を考えればいい？」 |
| **B2 日本語 D-Day Scenario Book** | ノルマンディー戦役＋シナリオ | 「この戦役は何だった？ このシナリオで何を狙う？」 |

### 一番簡単な使い分け

**処理に困った → A2**

**意味が分からない → A4**

**D-Day戦役・シナリオ固有のことを知りたい → B2**

---

## 英語3冊

英語版は、日本語版と同じ製品役割を持ちます。

| 本 | 対応 |
|---|---|
| A3 English Player Rulebook | A2相当 |
| A5 English Rules Companion | A4相当 |
| B3 English D-Day Scenario Book | B2相当 |

英語版は日本語の逐語訳ではありません。

同じ権威ソースと、承認済み日本語版の読者価値・製品役割を基準に、英語として直接作成されています。

---

## 権威関係

ユーザー向け文書の上には、2つの正本があります。

- **A1 Common Rule Canonical Source**  
  共通ルール意味論の正本。

- **B1 D-Day Scenario Canonical Source**  
  D-Dayシナリオ意味論の正本。

A2～A5はA1を勝手に変更できません。

B2/B3はB1を勝手に変更できません。

歴史解説に登場する実在の部隊・地名・作戦名も、そのままゲームデータにはなりません。

---

## 初めて読むなら

### ゲームをすぐ遊ぶ目的

1. B2でシナリオ全体をつかむ
2. A2で正式処理を確認
3. 分かりにくいところだけA4

### じっくり理解したい

1. B2 Part Iでノルマンディー戦役を読む
2. A4で作戦級ルールの意味を理解
3. A2で正式処理を確認
4. B2のプレイヤーガイドへ戻る

---

## プレイ中

プレイ中は全部を開く必要はありません。

基本は、

**A2を手元に置く。**

必要になったときだけ、

- 理由・意味 → A4
- D-Day固有条件・歴史・作戦 → B2

へ移ります。

文書が厚くなっても、役割を分けているため、実際に読む量を増やさず必要な答えへ行ける構造です。
